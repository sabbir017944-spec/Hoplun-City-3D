# Hoplun City — 3D Demo

A small, fictional industrial-district-inspired 3D browser prototype. This is a generic environment, not a precise map of a real factory or its security/access layout.

## Controls
- Desktop: WASD / arrow keys to move, Shift to run, click game and mouse to look around.
- Mobile: left joystick to move; drag on the right side to look.

## Run
Open `index.html` through a local web server or GitHub Pages. Three.js is loaded from a CDN, so internet access is needed.

## GitHub Pages
1. Repository Settings → Pages.
2. Choose **GitHub Actions** as the build source.
3. The included workflow deploys the root folder automatically when you push to main.
